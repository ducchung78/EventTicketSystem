3. Tích Hợp Jira – Quản Lý Lỗi
3.1 Tạo / Cập Nhật Issue
Kiểm tra issue tồn tại theo Testcase ID
Nếu chưa có → Tạo mới issue
Bug mới với Priority, Label automated-test
Nếu đã có → Cập nhật issue
Tăng số lần lỗi, cập nhật log, thời gian, trạng thái
Đính kèm file .log vào issue
TC-XX.log chứa đầy đủ error message
